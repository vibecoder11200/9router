当其他一切都受配额限制时的应急备用。零成本 24/7 编码!

概览

免费层提供商是订阅和低价配额都耗尽时的 回退:

  • 🆓 Kiro - 6 个免费模型(约 50 credits/月,含 Claude Sonnet 4.5 与 Haiku 4.5)
  • 🆓 OpenCode Free - 无需登录,模型列表自动获取,无限透传
  • 🆓 Vertex AI - $300 免费 GCP 额度(90 天,Gemini 3.1 Pro + 合作伙伴模型)

⚠️ 已停更的免费层: iFlow 自 2026 年起转为付费,Qwen Code 免费 OAuth 已于 2026-04-15 结束,Gemini CLI 已于 2026-06-18 停止服务(请改用你的 Google 账户配合 Antigravity)。

策略: 作为应急备用使用。付费层作为主力,免费层作为安全网!

OpenCode Free(无需登录)

价格

套餐月费模型配额
免费$0自动获取无限(模型列表会波动)

最佳价值: 设置最快——完全不需要账户。

设置

步骤 1:通过仪表盘连接

9router
# 仪表盘 → 提供商 → 连接 OpenCode Free

步骤 2:无需登录

  • 点击 "Connect OpenCode Free"
  • 模型列表自动从 opencode.ai/zen/v1/models 获取
  • 完成——无需账户,无需 OAuth

步骤 3:在 CLI 中使用

Model: oc/<auto>

专业建议

  • 零设置 - 连接最快的提供商
  • oc/<auto> - 在组合中使用此占位符;9Router 会自动选择可用模型
  • 列表会波动 - 可用模型会随时间变化,组合可以优雅地处理

故障排除

"OAuth failed"

方案:

  • 检查网络连接
  • 尝试其他浏览器
  • 清除浏览器缓存
  • 在仪表盘重新连接

"Model not available"

方案:

  • 检查仪表盘中提供商已连接
  • 确认 OAuth token 有效
  • 必要时重新连接提供商

"Slow responses"

方案:

  • 免费层优先级较低
  • 在非高峰时段使用
  • 切换到其他免费提供商
  • 升级到低价层以提速

限制

免费层注意事项

  • 速度 - 可能慢于付费层
  • 优先级 - 高峰期优先级较低
  • 速率限制 - 免费配额有限(Kiro 约 50 credits/月)
  • 可用性 - 偶尔可能宕机

方案: 使用 3 层回退策略保障可靠性!
